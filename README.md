# Portafolio comercial · Carlos González

Sitio estático de una sola página (HTML, CSS y JavaScript sin dependencias de compilación). Idioma: español.

## Archivos

- `index.html`: contenido y estructura.
- `styles.css`: identidad visual (grafito, turquesa y blanco).
- `script.js`: menú móvil, año del pie y botón de copiar correo.
- `vercel.json`: configuración mínima de Vercel.

## Publicar en Vercel

1. Crea un repositorio en GitHub (por ejemplo `portafolio-carlos-gonzalez`) bajo la cuenta Carlangatrex.
2. Sube estos archivos a la raíz del repositorio.
3. En Vercel: **Add New → Project**, importa el repositorio.
4. Framework Preset: **Other**. Deja vacíos Build Command y Output Directory.
5. Pulsa **Deploy** y abre la URL generada para verificar.

## Verificación antes de dar el sitio por publicado

- Abrir la URL en celular y en computador.
- Probar los enlaces: Kit de Seguimiento, checkout de Hotmart, Respiro, GitHub y el correo.
- Confirmar que el menú móvil abre y cierra.
